ZAC'S KNOWLEDGE TRACKER — VERSION 0.07
======================================
CONTENTS (four files to upload)
- index.html           updated homepage, adds Version .07 card
- exam-07.html         new Science/Humanities tutor page
- exam-07-bank.js      10 Humanities learning modules + 32 Science activities
- exam-07-app.js       hints, blocks, written responses, saving, marks and radar

INSTALLATION
1. Extract the ZIP to your computer.
2. Open the extracted Zac_Version_07_Upload folder.
3. In GitHub, open https://github.com/DrMaGr/zactests
4. Select Add file > Upload files on the repository's default branch.
5. Select the FOUR website files listed above and upload to the repository ROOT.
   Do not upload into a subfolder; relative script links expect the same directory.
6. Commit changes, allow GitHub Pages to publish, then open:
   https://drmagr.github.io/zactests/exam-07.html
7. Refresh with Ctrl+Shift+R if an older page is cached.

NOTES
- Version .07 has no timer. It does not touch Version .06 or older progress.
- Humanities uses ten teacher-provided historical extended-response themes.
  Every topic includes eight sentence blocks: four useful and four distractors.
  TEEL accepts Topic-Explain-Evidence-Link OR Topic-Evidence-Explain-Link.
  Students then draft their own paragraphs with guidance and a comparison model.
- Science has four targeted areas and 32 original practice activities, including
  circuit diagrams, Ohm's law, organelles and scientific investigations.
- MC answers are displayed in a shuffled order without changing marking.
- Objective questions score independent first correct attempts separately from
  aided answers. Written paragraphs are NOT falsely auto-graded as correct.
- History and radar charts use independent objective responses and are saved
  only in the browser's local storage; export JSON for backup.
- The included index.html was based on current GitHub source as of creation;
  if the homepage has since changed, merge its new Version .07 card rather
  than overwriting newer unrelated homepage modifications.
