ZAC'S KNOWLEDGE TRACKER — VERSION .06 GUIDED REVISION
==================================================

This is a learning and tutoring module, NOT an exam.
No timer, no formal exam scores, and no penalty for using hints.

UPLOAD THESE FIVE FILES TO THE ROOT OF:
https://github.com/DrMaGr/zactests

- index.html                 (replace existing homepage)
- exam-06.html               (replace retired .06 page)
- exam-06-app.js             (new guided-tutor interface)
- exam-06-bank.js            (replace previous .06 question bank)
- UPLOAD_README.txt          (optional, may upload alongside the other files)

GitHub instructions:
1. Open the repository linked above.
2. Select Add file > Upload files.
3. Drag the extracted files themselves into the GitHub upload page.
   Do not upload the ZIP file or upload an enclosing folder as the website root.
4. Commit changes; existing HTML/JS files must be replaced.
5. Open https://drmagr.github.io/zactests/ and hard-refresh (Ctrl+Shift+R).

VERSION .06 INCLUDES
- 225 ORIGINAL, guided activities across five subjects
- English / The Giver: 41
- Science / Cells, Systems & Electricity: 52
- Humanities / Japan and the Aztec conquest: 38
- French / vocabulary, grammar & reading: 50
- Maths / teacher-style revision booklet topics: 44
- Choose a small topic rather than having to complete the whole subject
- Untimed hints, plus a gentle optional reminder after a long pause
- Immediate reasoned feedback, unlimited retries and model-answer option
- Click-to-order sentence/working blocks, multiple choice, written and numerical answers
- Topic notes, short passages and original SVG diagrams
- Written answers accept APPROVED wording variants (e.g., 3rd person / third person)
- Save/resume, topic-confidence indicators, review of weak activities, JSON export

IMPORTANT
- New practice progress is stored in this browser (localStorage) separately from
  old .06 exam-attempt records, as well as separately from Versions .01–.05.
- The app accepts only approved equivalent short answers. It does NOT use open-ended
  AI marking or fuzzy string matching, to avoid awarding credit for wrong facts.
- Long quotations from the novel and third-party critical essays are not republished.
- Text-based passage summaries are original or paraphrased for revision.
- Internet is not required after the website's four core files are loaded.
- This package has NOT been published to your GitHub repository by ChatGPT.
